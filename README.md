# Najihh/homebrew-tap

Homebrew tap for **Weiß CODE** (`weiss`).

```sh
brew install Najihh/tap/weiss-code
```

`Formula/weiss-code.rb` is generated by the release workflow in
[Najihh/Weiss](https://github.com/Najihh/Weiss) from `packaging/weiss-code.rb.tmpl`.
Do not edit it by hand; the next release overwrites it.
